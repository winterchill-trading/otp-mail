# AGENTS.md: otp-mail/docs

`api-notes.md`: notes on the protocols and environment quirks behind the library: SMTP
(RFC 5321, 6409, 3207, 8314, 4954), TLS from Async, MIME (RFC 2045 to 2047, 5322), DKIM
(RFC 6376, 8301), one-time codes and PSD2 SCA, and quirks of the build environment.

Plain Markdown, not built by odoc. When a behaviour changes, update the matching section in the
same change and keep the RFC section references exact.
